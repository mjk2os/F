Practical No. 6

Aim: Create a simple key logger using python.

Key_demo.py:

import tkinter as tk
def key_pressed(event):
key = event.keysym
label.config(text=f&quot;Key pressed:{key}&quot;)
with open(&quot;keys_log.txt&quot;,&quot;a&quot;) as f:
f.write(key + &quot;\n&quot;)
root = tk.Tk()
root.title(&quot;Keyboard Input Logger (Educational)&quot;)
root.geometry(&quot;400x200&quot;)
label = tk.Label(root,text=&quot;Press any key...&quot;, font = (&quot;Arial&quot;, 14))
label.pack(pady = 40)
root.bind(&quot;&lt;KeyPress&gt;&quot;, key_pressed)
root.mainloop()

cmd command :

cd\
cd Path where file is stored
python key_demo.py
