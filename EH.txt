Practical No. 6

Aim: Create a simple key logger using python.

Key_demo.py:

import tkinter as tk
def key_pressed(event):
key = event.keysym
label.config(text=f"Key pressed:{key}")
with open("keys_log.txt","a") as f:
f.write(key + "\n")
root = tk.Tk()
root.title("Keyboard Input Logger (Educational)&quot;)
root.geometry("400x200")
label = tk.Label(root,text="Press any key...", font = ("Arial", 14))
label.pack(pady = 40)
root.bind("<KeyPress>", key_pressed)
root.mainloop()

cmd command :

cd\
cd Path where file is stored
python key_demo.py
